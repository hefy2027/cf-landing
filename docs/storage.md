# 存储管理：KV / D1 / R2

CF Manager 统一管理 Cloudflare 三大存储服务：KV（键值存储）、D1（关系型数据库）、R2（对象存储），提供可视化 CRUD 操作。

## 存储服务对比

| 特性 | KV | D1 | R2 |
|------|----|----|-----|
| **类型** | 键值存储 | Serverless SQLite | 对象存储（S3 兼容） |
| **一致性** | 最终一致 | 强一致 | 强一致 |
| **典型场景** | 配置 / 缓存 / 会话 | 结构化数据 / 排行榜 / CMS | 文件 / 图片 / 视频 / 静态资源 |
| **读延迟** | 毫秒级 | 毫秒级 | 毫秒级 |
| **写延迟** | 全局 < 60s | 毫秒级 | 毫秒级 |
| **免费配额** | 10 万读 / 天，1k 写 / 天 | 500 万行读 / 天，10 万行写 / 天 | 10 GB 存储，100 万 Class A 操作 / 月 |

## KV 管理

### 支持的操作

| 操作 | 说明 |
|------|------|
| 创建命名空间 | 创建新的 KV Namespace 并绑定到 Workers |
| 键值 CRUD | 可视化新增 / 编辑 / 删除键值对 |
| 批量操作 | 批量添加键值对，支持 JSON 导入 |
| 搜索 | 按 Key 前缀搜索，快速定位 |
| 过期时间 | 设置键值对的 TTL（过期秒数） |

### 典型使用

```
Key:     config:theme
Value:   "dark"
TTL:     - (永不过期)

Key:     session:abc123
Value:   {"userId": 1, "role": "admin"}
TTL:     3600
```

## D1 管理

### SQL 查询

内置 SQL 编辑器，支持：

- **查询执行**：SELECT、INSERT、UPDATE、DELETE 等标准 SQL
- **表结构变更**：CREATE TABLE、ALTER TABLE、DROP TABLE
- **结果导出**：JSON / CSV 格式下载
- **表列表**：一键查看数据库中所有表及其结构

### Schema 管理

| 操作 | 说明 |
|------|------|
| 初始化 | 从 `schema.sql` 一键建表 |
| 查看 | 展示所有表名、字段、索引信息 |
| 修改 | 在线执行 DDL 语句 |

## R2 管理

### 支持的操作

| 操作 | 说明 |
|------|------|
| 创建存储桶 | 创建 R2 Bucket |
| 上传文件 | 拖拽或点击上传，支持大文件 |
| 下载 | 一键下载文件 |
| 预览 | 在线预览图片 / 文本文件 |
| 删除 | 单个或批量删除文件 |
| 公开访问 | 管理存储桶的公开访问权限 |
| 自定义域名 | 绑定自定义域名访问 R2 内容 |

### R2 使用限制

- 单文件最大 5 TB（通过分片上传）
- 存储类为 Standard（单一存储类）
- 无出口流量费用（与 S3 的核心差异）

---

## 跨账户存储管理

CF Manager 支持在多个 Cloudflare 账户间统一管理存储：

- KV：跨账户查看和编辑所有命名空间
- D1：跨账户执行 SQL 查询，对比 Schema
- R2：跨账户浏览和迁移文件
