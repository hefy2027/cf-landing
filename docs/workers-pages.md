# Workers 与 Pages 管理

CF Manager 统一管理 Cloudflare Workers 脚本和 Pages 项目，支持单账户与跨账户批量运维。

## Workers 管理

### 功能概览

| 操作 | 说明 |
|------|------|
| 创建 / 编辑 | 在线代码编辑器，支持 JavaScript / TypeScript |
| 部署 | 单账户直接部署，跨账户一键批量部署 |
| 绑定 | KV / D1 / R2 / Service / Queue / Secret 等全类型绑定管理 |
| 环境变量 | 普通变量与加密 Secret，支持批量设置 |
| 路由 | 域名路由、调度规则、Pattern 匹配 |
| 自定义域名 | 绑定自定义域名并自动配置 DNS |
| 触发器 | Cron Triggers 定时任务调度管理 |
| 日志 | 实时 Tail 日志流，在线排查 |

### 跨账户批量部署

在 Workers 列表中选择多个账户的目标脚本，点击「批量部署」后系统自动：

1. 读取各账户最新脚本内容
2. 切换到目标账户，更新对应 Workers 脚本
3. 自动同步绑定与环境变量配置
4. 返回统一部署结果与日志

> 适合**同一套脚本在多个账户间同步**的场景，如多环境（开发 / 预发 / 生产）一致性部署。

## Pages 管理

### 功能概览

| 操作 | 说明 |
|------|------|
| 项目创建 | 创建 Pages 项目，关联 GitHub 仓库或直接上传 |
| 构建配置 | 配置构建命令、输出目录、分支与环境变量 |
| 部署历史 | 查看所有部署版本，支持一键回滚到任意版本 |
| 自定义域名 | 为 Pages 项目绑定自定义域名 |
| 环境变量 | 管理与加密 Pages 项目的环境变量 |
| 删除项目 | 归档与彻底删除 Pages 项目 |

### 版本回滚

部署历史列表展示每次部署的状态、提交信息与时间。点击任意历史版本即可**回滚**——系统会将生产环境回退到所选版本。

> 回滚仅影响生产环境，不会删除中间版本的部署记录。

---

## 双版本差异

| 特性 | Docker 版 | Worker (Pages) 版 |
|------|-----------|-------------------|
| API 调用方式 | Cloudflare SDK (Node.js) | Cloudflare REST API |
| 日志方式 | Tail API + 本地缓存 | 实时 Tail 推送 |
| 批量部署 | 全功能支持 | 受 CPU 时间限制，大并发需注意 |

### 注意事项

- **Worker 版 CPU 限制**：Free 计划 10ms/请求，批量操作过多可能超时。建议减少单次并发账户数或升级 Paid 计划。
- **路由冲突**：同一域名下多个 Workers 路由可能冲突，CF Manager 会在保存时做冲突检测并提示。
